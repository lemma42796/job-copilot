状态:**进行中** —— 已验证:依赖安装、migration 0025/0026 存量库回填、注册/登录/隔离(note/job 交叉 404)、充值与三链路扣费、出题 202+SSE+after_seq(单进程冒烟);全栈 compose 8 服务形态、队列水位 503、长任务与在线互压(k6 压测,见 `STATUS.md`)。剩余按下列顺序验证,每步失败即停:

1. 答题回合 / 结束总结两个 SSE 长任务端点各走通一次(提交评分已由压测的 `session_submit` job 覆盖)
2. session / jd 的跨用户交叉访问 404(note / job 已验)
3. worker 副本 1 → N,确认吞吐近似线性提升
4. 强杀一个 worker 进程,确认其未 ack 的任务被其他副本接管完成,无丢失、无重复扣费
5. 多副本同时跑 embed worker,确认同一批 chunk 只 embedding 一次、只扣一次费
6. 确认 API 容器内不再有任何后台常驻任务
7. 上游连续 429 后确认熔断打开 —— stub 永不 429,压测覆盖不到,用 `DummyProvider.queue_error()` 在单测里构造
8. `工作进程数 × (db_pool_size + db_max_overflow)` 不超过 PostgreSQL `max_connections`

`user_id` 过滤位置清单见交付报告,需逐条核对。
